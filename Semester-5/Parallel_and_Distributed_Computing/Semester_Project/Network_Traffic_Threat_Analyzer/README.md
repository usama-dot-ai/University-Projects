
# Network Traffic Threat Analyzer

## Project Overview

Network Traffic Threat Analyzer is a Java-based network traffic
analysis application that uses parallel processing and multithreading
to analyze network packets, identify suspicious traffic patterns
through rule-based detection, and present network statistics and
security alerts through a graphical user interface.

## Technologies

- Java 21
- JavaFX
- Maven
- Pcap4J
- JUnit
- Git and GitHub

## Main Features

- Offline PCAP file import and packet parsing
- Sequential and parallel packet processing
- Multithreaded traffic analysis
- Rule-based suspicious activity detection
- Network traffic statistics and visualization
- Performance comparison of sequential and parallel execution
- CSV report generation

## Project Structure

- `model/` - Shared application data models
- `capture/` - Packet collection and parsing
- `processing/` - Parallel processing engine
- `detection/` - Threat detection rules
- `reporting/` - Report generation
- `ui/` - JavaFX graphical interface
- `docs/` - Project documentation
- `test/` - Automated tests
