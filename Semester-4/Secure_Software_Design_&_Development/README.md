# Secure Software Design & Development

This repository contains the laboratory tasks and quizzes completed for the **Secure Software Design & Development** course. The coursework covers security fundamentals, secure software design, threat modeling, security controls, and practical security testing.

## Topics Covered

### Security Fundamentals

* Software bugs, errors, and failures
* Debugging and exception handling
* Functional and non-functional requirements
* Assets, threats, and security controls
* Security considerations across the SDLC
* Risk assessment fundamentals

### Secure Software Design

* Data Flow Diagrams (DFDs)
* State diagrams
* Use case and misuse case modeling
* Security requirements
* Security controls and mitigations
* Secure access control design

### Threat Modeling

* Attack trees
* STRIDE threat modeling
* DREAD risk assessment
* Trust boundaries
* Threat-to-control mapping
* MITRE ATT&CK framework
* Enterprise and Mobile ATT&CK matrices

### Security Testing & Analysis

* Static code analysis
* Dynamic web application testing
* HTTP request and response analysis
* Vulnerability identification
* Manual security testing
* Automated vulnerability scanning

## Tools Used

* **Microsoft Threat Modeling Tool**
* **Codacy**
* **Burp Suite**
* **OWASP ZAP**
* **MITRE ATT&CK Navigator**
* **FoxyProxy**
* **Firefox**

## Security Controls Covered

The coursework explored practical controls including:

* Multi-Factor Authentication (MFA)
* Role-Based Access Control (RBAC)
* Input validation
* Prepared statements
* TLS/HTTPS
* Secure session management
* Rate limiting and CAPTCHA
* Audit logging
* Encryption
* Network segmentation
* Firmware and security updates
