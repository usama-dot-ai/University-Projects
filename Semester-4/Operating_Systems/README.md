# Operating Systems

This repository contains the laboratory tasks, assignment, and quizzes completed for the **Operating Systems** course. The work focuses on Linux fundamentals, C++ system programming, process management, inter-process communication, multithreading, CPU scheduling, deadlock detection, and Bash scripting.

## Topics Covered

### Linux Basics & File Management

**Lab Tasks 1–3**

* Linux command-line navigation and file management
* File creation using `vi` and `nano`
* User identification
* File investigation techniques
* File permissions and ownership
* Permission management using `chmod`

### C++ Fundamentals & CLI Tools

**Lab Task 4 & Assignment 1**

* Basic C++ programming structures
* Command-line arguments using `argc` and `argv`
* String analysis
* Command-line calculator development
* Input validation and error handling, including division by zero

### Process Management & IPC

**Lab Tasks 5–8**

* Process creation using `fork()`
* Program execution using `exec()`
* Process synchronization using `wait()`
* Inter-process communication using anonymous pipes
* Shared memory
* Linux system calls

### Multithreading

**Lab Task 9**

* POSIX threads (`pthreads`)
* Thread creation and execution
* Thread management
* Programs with and without thread joins

### CPU Scheduling

**Lab Tasks 10–11**

* First-Come, First-Served (FCFS)
* Shortest Job First (SJF)
* Scheduling with and without arrival times
* Scheduling metric calculations
* Text-based Gantt charts

### Deadlock Detection

**Lab Task 13**

* Resource allocation and request matrices
* Safe-state analysis
* Deadlock detection
* Matrix-based resource analysis

### Bash Scripting

**Quiz 1**

* User input and conditional statements
* String and file tests
* Logical and arithmetic operations
* Command-line arguments
* `case` statements
* Arrays and loops
* Functions

### Multi-Process Architecture

**Quiz 2**

* Multi-process fraction calculator
* `fork()` and pipes
* Parent-child communication
* Fraction arithmetic
* Euclidean algorithm for fraction simplification
* Error handling

## Technologies

* **C++**
* **Bash**
* **Linux**
* **POSIX Threads**
* **Linux System Calls**
* **Inter-Process Communication (IPC)**

## Learning Outcomes

This coursework provided practical experience with fundamental Operating Systems concepts, including **processes, threads, IPC, CPU scheduling, deadlocks, Linux system administration, and shell scripting**.
