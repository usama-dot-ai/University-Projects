# Network Security

Practical coursework covering **network reconnaissance, network defense, routing, secure access, traffic analysis, penetration testing, and applied cryptography**.

## Areas Covered

* Network Reconnaissance & Troubleshooting
* Linux & Windows Firewall Configuration
* Static Routing, EIGRP & GRE Tunnels
* SSH, Telnet & Remote Administration
* Standard & Extended ACLs
* DHCP Snooping
* ARP Spoofing & MITM Attacks
* Wireshark, Bettercap & Ettercap
* DoS Attack Demonstrations
* Substitution Ciphers & AES
* OpenSSL & Network Security Testing

## Key Practical Skills

### Network Defense

* Configured inbound and outbound firewall rules
* Implemented standard and extended ACLs
* Configured DHCP Snooping with trusted ports
* Applied application- and port-based traffic filtering

### Network Infrastructure

* Configured static routes
* Implemented EIGRP
* Built GRE tunnels
* Verified interfaces, routing tables, and connectivity

### Security Testing & Analysis

* Performed ARP spoofing demonstrations
* Analyzed MITM traffic
* Captured HTTP requests with Wireshark
* Demonstrated cleartext credential exposure
* Observed SYN and ICMP flooding through packet analysis

### Cryptography

* Implemented substitution cipher encryption/decryption
* Generated substitution keys using Python
* Used OpenSSL for AES encryption
* Compared AES-128-ECB and AES-128-CBC
* Demonstrated BMP image encryption
